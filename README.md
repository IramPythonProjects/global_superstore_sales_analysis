# 📊 Global Superstore Sales Analysis

## 📌 Project Overview

This project focuses on analyzing Global Superstore sales data using Python.

The main objective is to explore sales performance, 
profit distribution, product performance, and regional 
sales trends to generate meaningful business insights.

## 🎯 Project Objectives

- Analyze overall sales and profit.
- Identify the best-selling product categories.
- Compare sales performance across regions.
- Analyze profit by category.
- Identify the top 10 products by sales.
- Generate useful business insights.

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## 📂 Dataset Information

Dataset: Global Superstore Dataset

The dataset contains information about:
- Orders
- Products
- Categories
- Sales
- Profit
- Quantity
- Regions
